누적 순매수 · 방식 C (TAKER)

C 체결: 시장가로 먼저 달려든 쪽이 매수였나 매도였나

C 방식은 추정이 아닙니다. 바이낸스가 봉마다 직접 주는 taker buy 체결량을 그대로 쓰고, 나머지를 taker sell 로 봅니다.

체결 한 건에는 taker 가 정확히 한 명 있다

Maker호가창에 지정가 주문을 걸어 두고 기다린 쪽
← 체결 →
Taker걸려 있는 주문을 바로 가져간 쪽 (시장가 등)
taker buy
taker 가 사는 쪽. 매도 호가를 먹으며 올라간 체결입니다.
taker sell
taker 가 파는 쪽. 매수 호가에 던진 체결입니다.

모든 체결은 둘 중 하나이므로, 전체 거래량에서 taker buy 를 빼면 남는 것이 전부 taker sell 입니다. 바이낸스가 taker sell 을 따로 주지 않는 이유입니다.

공식

매수 = taker buy 금액  ← 봉의 11번째 값 (taker buy quote asset volume)
매도 = 거래대금 − taker buy 금액  ← 거래대금은 봉의 8번째 값 (quote asset volume)
순매수 = 매수 − 매도 = 2 × taker buy 금액 − 거래대금

코인 수로 볼 때는 같은 식에 taker buy 수량(10번째 값)과 거래량(6번째 값)을 넣습니다.

이 숫자가 표의 한 줄이 되기까지

  1. 봉마다 순매수를 구한다서버는 1분봉마다 위 공식을 적용합니다.
  2. 기간만큼 더한다고른 기간(1개월 ~ 전체)의 순매수를 모두 더한 것이 누적 순매수입니다. 그래프는 이 합이 쌓여 가는 모습입니다.
  3. USDT 로 바꾼다호가 자산이 USDT 가 아니면(ORCA/TRY, ORCA/USDC 등) 그날의 환율로 USDT 금액으로 바꿉니다.
  4. 같은 코인의 페어를 합친다ORCA/USDT + ORCA/USDC + ORCA/TRY 를 더해 ORCA 한 줄로 만듭니다.
  5. 유통량으로 나눈다표의 "÷ 유통량" 열은 누적 순매수 코인 수 ÷ 유통량(CoinGecko)입니다.

읽을 때 알아 둘 점

  • 사는 사람과 파는 사람의 수량은 언제나 같습니다. 순매수는 "누가 더 샀나"가 아니라 "어느 쪽이 더 급하게 호가를 먹었나"를 잽니다.
  • 지정가를 깔아 두고 받아 모으는 매집은 상대방의 taker sell 로 잡힙니다. 조용히 모으는 동안 순매수가 오히려 음수로 나올 수 있습니다.
  • 바이낸스 현물 체결만 봅니다. 선물, 다른 거래소, 장외 거래, 입출금은 들어 있지 않습니다.
  • A 경로·B 종가 방식은 가격 움직임으로 매수·매도를 추정한 값이고, C 만 실제 체결 기록입니다.
