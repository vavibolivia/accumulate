WPF PC 앱 빌드·실행 (윈도우)

1. .NET 8 SDK 설치: https://dotnet.microsoft.com/download/dotnet/8.0
2. Java 17 이상 설치 (실행할 때 필요): https://adoptium.net
3. build-windows.bat 더블클릭
   → 테스트 후 dist\BinanceCumulative.exe 와 binance-cumulative-server.jar 가 생김
4. dist\BinanceCumulative.exe 실행 → 계산 서버를 창 없이 켜고 전체화면 대시보드가 열림

Visual Studio 2022 로 열기: BinanceCumulative.Pc.sln → BinanceCumulative.Pc 를 시작 프로젝트로
  (디버그 실행 시 binance-cumulative-server.jar 를 bin\Debug\net8.0-windows\ 에 복사해 두면 서버 자동 실행)

  (디버그 빌드는 이 폴더의 binance-cumulative-server.jar 를 자동으로 출력 폴더에 복사합니다)

java 찾기: 설정에 지정한 경로 → JAVA_HOME → PATH → C:\Program Files\{Eclipse Adoptium, Java, ...}.
  PATH 의 java 가 8 처럼 17 미만이면 건너뛰고 17 이상인 것을 고릅니다.

로컬 DB: %AppData%\BinanceCumulative\app.db (SQLite). 설정, 순위·그래프 저장본, 종목별 일별 집계(daily_agg).
  설정 창에서 DB 폴더 열기 · 일별 집계 CSV 내보내기 · 그래프 저장본 비우기.

빌드·테스트 확인: 2026-11-14, .NET SDK 9.0.305 / 런타임 8.0, 테스트 16개 통과.
